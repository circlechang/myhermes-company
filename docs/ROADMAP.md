# Roadmap
- **M0 地基（本週）**：API server 開通驗證；FastAPI 骨架；公司/成員/Agent 資料模型；chat 代理（runs SSE 轉 WebSocket）；`pytest` 綠。
- **M1 工作臺（週 2）**：React 登入＋工作臺＋聊天（串流、工具卡、核准卡）；Agent 管理頁；zh-TW。
- **M2 工作流（週 3–4）**：畫布（DAG）、執行器、閘門、run 快照回看、排程、LINE 投遞。
- **M3 公司化（週 5）**：多公司、角色、看板整合、用量成本、稽核。
- **M4 商用化（週 6+）**：安裝器、Docker、授權金鑰、文件。
